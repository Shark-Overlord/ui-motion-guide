# 按所选分支验证

这些是添加动效后目标组件的验收点，不代表随附原始示例已经通过生产验收。修改业务组件后应在其运行页面操作；只编辑 skill 文档时，检查入口、引用、来源完整性与决策可用性即可。

## 入口与修改范围检查

| 请求或后续选择 | 应得出的决定 |
| --- | --- |
| 修改 `SaveButton.tsx` 中的保存按钮 | 读取该按钮并识别类别，直接进入 buttons 决策树；不重复请求同一范围的同意 |
| 给当前页面加点动效；或只提供页面路径 | 确定当前界面，只读扫描并列出候选；用户选择前不匹配动效叶子、不修改项目 |
| 候选列出后用户没有答复 | 等待选择；不把沉默当成同意 |
| 用户选择“1 和 3” | 只为 1 和 3 识别类别并匹配动效，保留未选项；不把输入框强行归入 buttons |
| 用户选择“上面全部” | 对本次列出的全部候选逐项分类并实现，不再重复确认同一范围 |
| 只检查这个工具栏并给建议 | 保持只读，即使目标明确也不自动实施 |
| 无运行页面，只能读取源码 | 标明源码推断，不声称扫描了用户当前可见界面 |

## 共同检查

- 页面初次挂载直接落在正确状态，不从零宽度或屏幕原点飞入。
- 鼠标、键盘和触摸能完成已有主要操作；禁用项没有新动作。
- 快速进入/离开、反复打开/关闭、连续点击与异步乱序不会让旧回调覆盖新状态。
- 正常和减少动态效果下最终业务状态相同；JS 帧循环也正确停止。
- 检查长文案、中文/emoji、窄容器和字体加载后的布局；固定槽稳定、有意伸缩连续。
- 看目标浏览器实际运行及 computed 样式：所有引用的 token 有定义，隐藏旧层不挡点击、不吸走焦点，没有重复事件或永不结束的动画帧。

## 分支验收

| 分支 | 最小有意义的操作 |
| --- | --- |
| L1 | hover、按住后移出、键盘激活、两段不同长度文案切换 |
| L2 | 真实成功/失败、快速重复触发、组件卸载时请求结束 |
| L3 | 成功写入、拒绝写入、快速再复制，结果提示与实际剪贴板结果对应 |
| L4 | 打开后 Escape、外部点击、选择项、快速关闭再打开，焦点返回可操作入口 |
| L5/L8 | 首次进入末项、跨分隔缝移动、键盘跨项、禁用项、容器缩放/滚动后高光定位 |
| L6 | 25 → 100 → 400 → 25，快速正反更新，减弱动态效果直接最终值 |
| L7 | 展开后边界位置的鼠标停留、快速跨项、键盘 focus、触摸、成功文案恢复 |
| L9 | cancel、提前松开 hold、countdown取消、请求失败重试；只对可恢复操作测试 Undo |
| L10 | 快速来回切换、持久状态与图标一致、路径插值失败时 fallback 清晰 |

## 决策推演场景

用这些请求检查 skill 是否能给出可执行方案，重点看机制和业务边界，而不是复述文档。

| 请求 | 应得出的决定 |
| --- | --- |
| 给保存按钮加提交反馈；项目使用 React | L2；沿用 React 状态/生命周期，绑定实际请求结果，不迁移 demo IIFE |
| Copy 点击后显示对勾，但复制可能失败 | L3；根据结果进入 copied/error；不能无条件展示成功 |
| 缩放从 25% 变 100% 时工具栏别跳动 | L6 + 必要的 L5；最大合法文本占位，数字方向连续 |
| 发布旁边的菜单平滑展开 | L4；主次事件隔离，关闭后焦点可达性正确 |
| 浮动纵向工具栏，跨项时高光连续 | L8；按容器坐标测量，高光首次就地出现 |
| 图标按钮 hover 后展开文字 | L7；按最大文字测宽，处理变宽造成的命中边界变化 |
| 删除按钮支持取消倒计时，服务端不能恢复删除 | L9 + L2；保留取消窗口，完成后不伪造 Undo |
| 日月图标过渡并切换全站主题 | L10 图标机制 + 目标项目主题状态；明确缺少独立 theme-switch 成品 |
| 普通弹窗淡入，布局保持原样 | 说明当前库无弹窗成品；迁移 opacity/transform 机制并保留弹窗焦点模型 |

交付时分别说明源码核对、结构检查、实际运行检查，未做浏览器检查不能报告“动效已验证”。
