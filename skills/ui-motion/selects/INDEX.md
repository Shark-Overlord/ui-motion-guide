# Selects 类别索引

选择与过滤交互组件，涵盖紧凑单选、可搜索组合框、容器形变面板、多选标签收集器以及流式过滤标签组。根据用户交互意图查表选定组件。

## 意图路由表

| 用户交互意图 / 状态变化 | 核心机制 | 推荐组件 |
| --- | --- | --- |
| 紧凑表单单选：选项适中（3~10 项），选值切换需要方向性感知的机械滚轮翻转文案 | 方向性滚轮位移与微模糊、面板 150ms 弹性展开、失焦去黑边 | [select.md](select.md) |
| 大量选项实时搜索：键入关键词即时过滤，支持一键清空与快速键盘漫游 | 浮动面板弹性升降（260ms）、过滤高度平滑收敛、清除按钮微缩显隐 | [combobox.md](combobox.md) |
| 高级仪表盘内联选择：触发胶囊需要直接膨胀变形为卡片浮层，保持容器视觉连续性 | 原地表面连续形变（400ms）、盖板值提升与微模糊置换、共享滑动高光条 | [morph-select.md](morph-select.md) |
| 收集型多选标签：在输入框内容纳多项已选胶囊，超出部分折叠为滚轮数字 | 标签槽位 260ms 微模糊展开、溢出轮盘 0.5em 翻滚、列表对勾实时描边 | [multi-select.md](multi-select.md) |
| 原地多维分类筛选：标签平铺流动换行，支持折叠展开与勾选位移让位 | 弹性位移滞后（FLIP 谐振子）、18px 勾选槽展开、SVG 描边书写、+N 错峰展开 | [chip-group.md](chip-group.md) |

## 跨类别分流

- 单纯的二值开关或布尔切换 → [switch](../toggles/switch.md)
- 表单复选框或协议勾选 → [checkbox](../toggles/checkbox.md)
- 互斥的横向分段按钮胶囊 → [segmented-control](../toggles/segmented-control.md)
- 弹出式操作菜单或上下文指令清单 → [dropdown-menu](../menus/dropdown-menu.md)
