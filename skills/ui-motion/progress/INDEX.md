# Progress 类别索引

进度、加载、倒计时、向导与用量计量组件及其直接关联的微交互、弹簧填充、数字滚轮与骨架屏置换流转。根据用户交互意图查表选定组件。

## 意图路由表

| 用户交互意图 / 状态变化 | 核心机制 | 推荐组件 |
| --- | --- | --- |
| 重要活动或大促截止倒计时：多单位时钟递减、机械数字滚轮翻牌、零抖动尺寸锁定 | 0-9 垂直数字滚轮、Ghost Sizer 零抖动物理锁、秒级精准对齐与归零状态置换 | [countdown.md](countdown.md) |
| 文件传输或数据同步完成度：已知范围的线性百分比填充、完成态对勾弹出与变色 | 标量弹簧 GPU 平滑填充、200ms 延迟成功变色、对勾弹性切入与等宽数字防抖 | [progress.md](progress.md) |
| 未知耗时的异步数据加载占位：杜绝累积布局偏移（CLS）、数据返回后平滑变身 | 90ms 错峰呼吸波浪脉冲、容器高度平滑自适应弹簧伸展、骨架与真实内容无缝交叉淡化 | [skeleton.md](skeleton.md) |
| 多阶段复杂任务或流程分步向导：清晰指引步骤顺序、支持回退与错误提示 | 方向感知流水线错峰推进、节点圆环与字形弹簧形变、连线标量弹簧贯通与对勾书写 | [stepper.md](stepper.md) |
| 复合资源配额与限额监控：多分类占比同时展示、限额阈值警示与图例悬停高亮 | 多分段错峰弹性揭示、限额刻度线与超额斜纹覆盖、图例聚焦隔离预览与联动 | [usage-meter.md](usage-meter.md) |
