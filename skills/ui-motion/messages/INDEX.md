# Messages 类别索引

消息、通知、警示与公告组件及其直接关联的微交互、入场弹簧、手势轻扫与高度伸展流转。根据用户交互意图查表选定组件。

## 意图路由表

| 用户交互意图 / 状态变化 | 核心机制 | 推荐组件 |
| --- | --- | --- |
| 页面内联警示或任务反馈：需要展示严重级别状态，文案切换微模糊置换，带平滑折叠关闭 | 四色调图标弹簧切入、文本 240ms 微模糊升降形变、容器平滑高度伸缩与折叠 | [alert.md](alert.md) |
| 全站顶栏广播或运营通知：多条通栏轮播、倒计时翻牌、悬停智能定格与折叠收拢 | 垂直 60%/70% 位移模糊翻页、自动轮播环形进度、悬停失焦暂停与高度折叠 | [announcement-bar.md](announcement-bar.md) |
| 局部异步操作完成的瞬态轻量反馈：自动消失，支持触控/光标单指手势轻扫丢弃 | 16px 弹簧升起微缩、80px/480px/s 水平轻扫抛掷丢弃、4500ms 自动倒计时与悬停暂停 | [toast.md](toast.md) |
| 多条并发系统通知层叠管理：节省屏幕空间，默认 3D 窥视堆叠，悬停展开为纵向列表 | 14px 阶梯窥视堆叠、悬停聚焦手风琴式纵向展开、单卡独立抛掷与队列升阶 | [toast-stack.md](toast-stack.md) |

## 跨类别分流
