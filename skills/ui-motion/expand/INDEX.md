# Expand 类别索引

区域展开、折叠、双维形变与尺寸弹性交互。根据用户交互意图查表选定组件。

## 意图路由表

| 用户交互意图 / 状态变化 | 核心机制 | 推荐组件 |
| --- | --- | --- |
| 常见问题与多节列表折叠：垂直多条目信息分段收起与按需展开，带高度平滑过渡与折角箭头旋转 | 真实高度 400ms 平滑展开与收起、内部文字微模糊升起、折角箭头 180° 旋转弹簧、上下键循环巡礼 | [accordion.md](accordion.md) |
| 摘要卡片原地膨胀：任务检查清单或进度概览在原地同时拉伸宽度与高度，展开完整交互面板 | 双维横纵 400ms 弹簧拉伸、内部内容锁定防抖物理宽度、副标题逐词微模糊形变、Escape 焦点逃生 | [expandable-card.md](expandable-card.md) |
| 工作区多栏布局拖拽：IDE 或工作台两侧侧边栏与主内容区的横向宽度自由按需拖动与微调 | 相对比例初始化与像素级 1:1 跟手拖拽、极限橡皮筋阻尼衰减、极限折叠与飞掷、双击重置默认比例 | [resizable-panels.md](resizable-panels.md) |
| 局部超长列表滚动：侧边栏或小部件中内容溢出，需要彻底清除浏览器灰色灰条并提供渐隐指引 | CSS Mask 动态边缘渐隐羽化遮罩、自定义浮动滚动条滑块、900ms 停留缓冲柔和淡出、指针拖拽映射 | [scroll-area.md](scroll-area.md) |

## 跨类别分流

- 同级内容或视图水平药丸切换 → [tabs](../navigation/tabs.md)
- 屏幕中心浮起的模态对话框 → [dialog](../overlays/dialog.md)
- 移动端或底部滑出的半屏交互面板 → [bottom-sheet](../overlays/bottom-sheet.md)
