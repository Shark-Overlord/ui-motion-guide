# Overlays 类别索引

浮层、弹窗、抽屉与悬浮提示。根据用户交互意图查表选定组件。

| --- | --- | --- |

| 破坏性操作与重大决策二次确认：需要强模态阻断背景、居中缩放弹簧升起与视口滚动条锁定 | 居中 400ms 缩放升起微弹簧、背景 7px 毛玻璃渐隐遮罩、滚动条差值 paddingRight 补偿、焦点陷阱 | [dialog.md](dialog.md) |
| 侧边滑动查阅或编辑详情：需要从屏幕或局部容器右侧滑入、头部手势拖拽退出与模态隔离 | 400ms 侧滑弹簧滑入、头部指针拖拽与 300px/s 飞掷退出、Viewport 与 Contained 双模式、Escape 焦点归还 | [drawer.md](drawer.md) |
| 提及与链接富文本卡片悬停预览：需要 500ms 冷启动意图防抖、300ms 预热快速切换与走廊保护 | 500ms 冷启动与 80ms 预热切换、140ms 离开走廊缓冲、视口防碰撞上下翻转、Tab 聚焦即时唤出 | [hover-card.md](hover-card.md) |
| 字段旁点击展开微型表单或复杂解释：需要紧贴触发器弹出、智能碰撞翻转与点击外部关闭 | 锚定跟随与视口防遮挡翻转、400ms 原点对齐缩放弹簧、点击外部延迟关闭、WAI-ARIA Dialog 闭环 | [popover.md](popover.md) |
