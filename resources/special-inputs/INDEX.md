# Special Inputs 类别索引

专项格式与结构化输入交互模型。涵盖数字滚轮步进器、多币种金额格式与分位镜像、国际区号单平面形变选择器、多标签胶囊共享高亮环与 FLIP 重排、文本域镜像定位 @/# 提及建议面板，以及物理键帽快捷键录制与冲突校验。

## 意图路由表

| 用户交互意图 / 状态变化 | 核心机制 | 推荐组件 |
| --- | --- | --- |
| 数字加减步进与直接输入：需要每一位数字独立滚轮滚动、长按指数级加速步进、拖拽标签微调数值、触及最大/最小边界时产生弹力反冲与微抖动 | 0-9 循环数字滚轮列（`wheel`）、长按指数衰减定时器（`150 * 0.86^n`）、越界弹簧反冲（`kick`）与按钮摇晃、拖拽 Scrubbing 阻尼 | [number-field.md](number-field.md) |
| 货币与金额输入：需要按币种精度（如 USD 2 位小数、JPY 0 位）实时格式化千分位、未填位半透明幽灵占位、切换币种时货币符号宽度弹簧形变、超额时横向拒绝回弹 | 最小货币单位（minor unit）换算、透明输入框 + 镜像字符列方向性模糊翻转、容器超宽自适应缩放（`fit`）、快捷加额胶囊与币种下拉菜单 | [money-input.md](money-input.md) |
| 国际电话号码输入：需要区号按钮原地单平面拉伸展开为带搜索的国家列表、按国别号段实时格式化并显示灰色剩余位引导掩码、合法时弹出对勾 | 单容器几何形变（`width`/`height`/`borderRadius` 同步补间为下拉面板）、未输入位掩码引导（`guide`）、键入 `+` 自动唤醒区号检索、国旗切换方向性位移 | [phone-input.md](phone-input.md) |
| 多标签/关键词胶囊输入：需要回车生成胶囊、首次退格选中末尾标签、二次退格删除、方向键切换选中时高亮环平滑滑动、增删换行时 FLIP 平滑重排 | 共享选中高亮环（`translate` + `width`/`height` 弹簧跟随）、两步式安全退格删除、重复标签脉冲放大提示（`scale(1.06)`）、多行容器高度与 FLIP 布局过渡 | [tag-input.md](tag-input.md) |
| 富交互 @提及 / #频道输入：需要在原生 textarea 中输入 `@` 或 `#` 时精准跟随光标弹出建议浮层、正文中实时高亮已选提及胶囊、随行数自适应高度 | 透明文本域 + 同步镜像背景层（`.mention-input-backdrop`）渲染高亮 Token 与锚点测量、光标坐标跟随浮层、键盘上下滑动高光药丸 | [mention-input.md](mention-input.md) |
| 键盘快捷键录制与绑定：需要点击进入录制态、实时映射按下的修饰键与主键为物理键帽、校验修饰键缺失或快捷键冲突并提供覆盖确认 | 物理键帽槽位复用与 FLIP 横向位移、录制态脉冲圆点、修饰键实时按压反馈（`data-pressed`）、冲突拦截警告与自适应高度提示槽 | [shortcut-recorder.md](shortcut-recorder.md) |

## 跨类别分流

- 常规单行文本输入（无特殊格式掩码或内嵌胶囊） → [input](../text-fields/input.md)
- 多行纯文本域（无 `@`/`#` 词法解析与光标浮层） → [textarea](../text-fields/textarea.md)
- 带清除按钮的搜索输入框 → [search-field](../text-fields/search-field.md)
- 按钮组内的数字滚轮计数徽章 → [button-group](../buttons/button-group.md)
