# Avatars 类别索引

用户形象展示、团队协同头像组与轻量状态徽标。根据交互意图与场景查表选定组件。

## 意图路由表

| 用户交互意图 / 状态变化 | 核心机制 | 推荐组件 |
| --- | --- | --- |
| 单用户资料展示：需要网络图片异步平滑淡入（高斯模糊消退）、加载失败首字母缩写兜底、以及在线/离线标记物理弹簧弹性切换 | 异步图片 240ms 渐现、首字母兜底提取、状态点 260ms 阻尼弹簧入场与 160ms 微缩退出 | [avatar.md](avatar.md) |
| 多成员重叠展示与协同操作：需要重叠紧凑排布、鼠标悬停扇形展开、单项浮起与邻项侧向避让、姓名气泡浮层与 `+N` 超额人数滚轮 | 扇形几何展开公式（`--fan`）、两翼让位（`--aside`）、60ms 意图防抖气泡、超额人数垂直滚动切变 | [avatar-group.md](avatar-group.md) |
| 实体状态/分类标签/审阅标记：需要文本更新时垂直微模糊形态切变、图标弹性进场、以及根据文案长短平滑拉伸外宽 | 文本垂直微模糊双图层置换、图标弹簧缩放、120ms 意图捕获窗口与 420ms 宽度自适应弹簧收敛 | [badge.md](badge.md) |

## 跨类别分流

- 实体卡片点击展开全屏高斯景深快速预览 → [card](../cards/card.md)
- 堆叠卡片手势拖拽滑动决策（通过/归档） → [card-stack](../cards/card-stack.md)
- 带有动态数字滚轮与涨跌幅指标统计卡片 → [metric-card](../cards/metric-card.md)
- 异步操作流转与逐字形变提交按钮 → [action-button](../buttons/action-button.md)
