# Cards 类别索引

内容展示卡片、手势交互堆叠卡片与指标看板卡片。根据用户交互意图查表选定组件。

## 意图路由表

| 用户交互意图 / 状态变化 | 核心机制 | 推荐组件 |
| --- | --- | --- |
| 实体内容卡片与沉浸式大图快速预览：需要悬停微浮起与图片变焦微放大、点击原地展开为全屏高斯磨砂景深弹层、收藏状态双向同步与 Esc 键安全退出 | 封面 600ms 变焦放大、背景 14px 景深虚化与全屏 16px 磨砂遮罩、弹层 320ms 弹簧缩放展开、Esc 焦点闭环恢复 | [card.md](card.md) |
| 多卡片堆叠与轻量手势快筛决策：需要类似 Tinder 的跟手拖拽与正负物理倾斜旋转、左右滑动显现 PASS/KEEP 决策印章、临界高速甩飞抛掷、以及卡片反飞撤销 | 指针拖拽与极性倾斜物理（`x * 0.065deg`）、印章透明度插值、临界抛掷飞出（500ms 弹簧与 120ms 淡出）、4 层深度推进、错峰 Stagger 恢复 | [card-stack.md](card-stack.md) |
| 数据指标看板与周期趋势监控：需要大号数字变动时平稳机械垂直滚动（绝对 0 像素外框抖动）、涨跌幅胶囊宽度弹簧自适应拉伸、以及分段周期切换 | 零抖动幽灵占位符（Ghost Sizer）+ 垂直数字滚轮、涨跌胶囊 420ms 宽度弹簧形变、标题与对比文案 240ms 微模糊置换、Roving Tabindex 周期切换 | [metric-card.md](metric-card.md) |
